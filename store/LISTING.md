# BP26 Badge Emulator

## App name

BP26 Badge Emulator

## Short description

Run the Breakpoint 26 badge on Android

## Long description

Boot Solana OS on an interactive recreation of the Breakpoint 2026 badge. Use the D-pad, Select, Cancel, and Boot controls to explore the firmware's launcher, Guide, and built-in apps.

The emulator bundles Solana OS 2.5.1 and boots offline. Join Emulator Guest in the badge's Wi-Fi menu to use your phone's internet connection for the badge App Store and account linking. Downloaded badge apps and their files stay on the virtual microSD card between sessions.

BP26 Badge Emulator is an independent companion app for exploring the badge on Android.

## What's New

First release. Includes Solana OS 2.5.1, a wider pixel-scaled display, persistent app storage, and a shortcut to link your badge in the browser.
